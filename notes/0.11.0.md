Kind: breaking

- **Works with whichever modules do the job.** A review is drafted into the module on your kehikko that keeps draft reviews, its checklist answers go to the module that keeps your checklists, a one-way briefing goes to the module that keeps the epic's document, and a diagram to the one that draws them. Each is found by what it does and called by its own name in what Factory tells you.
- **Says plainly when something is missing.** With nothing on hand to keep draft reviews, checklists, documents or diagrams, the review says so in general words and keeps the result in its record.
- **Posting by itself needs no secret file.** A two-way review you allowed Factory to post is sent with proof that it comes from Factory, which the module keeping the draft checks. A module keeping drafts that still expects the old secret file refuses that send, and the review then waits for you to send it; update that module to have Factory post again.
- **Other modules can show a job's stage.** A module showing an issue can now say where Factory's job for it stands.

## For agents

- `/review-factory` checks at run time that a module keeping draft reviews is placed on the conversation's kehikko, and names that module (or "a module that keeps draft reviews") when it is not.
- The diagram drawer is told the drawing module's name and tool as that module declares them; write the diagrams with that tool.
